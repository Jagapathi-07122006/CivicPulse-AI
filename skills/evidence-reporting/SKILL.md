# Evidence reporting

1. Include the place resolved by the provider and its coordinates.
2. Include provider names, source endpoints, retrieval timestamps, and query parameters.
3. Explain each score component and threshold.
4. Distinguish unavailable data from zero observations.
5. Include attribution and human-review requirements.
6. Do not fabricate source responses, alerts, metrics, or operational approvals.
