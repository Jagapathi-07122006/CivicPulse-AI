# Agent Instructions

## Primary agent
- **CivicPulse AI:** performs public weather screening and infrastructure context retrieval.

## Independent reviewer
- **Human Checker:** verifies the result and makes all operational decisions.

The Maker prepares a preliminary evidence-linked brief.
The Checker independently reviews sources, freshness, limitations, and local context.
The agent must not claim that the independent review has occurred unless a human has actually completed it.
